## ✨ Key Features

### 🎮 Gamified Ecosystem
- **Neural Level System** — Earn XP for every habit and focus session. Progress from *Novice* to *Eternal* with custom RPG-style attributes.
- **Neural Web Alignment** — A sophisticated Radar Chart in the Insight Dashboard mapping your growth across **Vitality · Intellect · Discipline · Zen · Focus**.
- **Momentum Score** — A real-time dynamic metric that scales with your productivity volume, mood, and focus consistency.

### 🧠 Neural Reflection (Journaling)
- **Deep Journaling** — Log daily wins and reflections in a beautiful glassmorphic interface.
- **Voice-to-Text Sync** — Transcribe thoughts instantly using integrated Web Speech API.
- **Sentiment Analysis** — Analyzes journal entries to produce a *Neural Resonance* score and correlate mindset with results.

### 🧘 Focus Chamber (Zen Mode)
- **Focus Modes 2.0** — Specialized protocols: *Deep Work*, *Learning*, *Zen*, and *Coding* — each with unique visual indicators.
- **Immersive Breathing Guide** — An animated Neural Orb visualizer that guides breath during sessions to optimize coherence.
- **Session History** — Track every second of focus with a detailed intensity timeline.

### 🔮 Neural Sync (AI Assistant)
- **Neural Prophecy** — Advanced insight engine analyzing productivity patterns and mood trends to deliver motivational prophecies and actionable advice.
- **Interactive AI Sync** — Kinetic visualizations representing your data being processed and synchronized.

### 🛡️ Resilience Architecture
- **Emergency Protocols** — High-security console with pulsing status indicators and red-alert aesthetics to safeguard streaks during high-friction cycles.
- **Streak Shield** — Preserve progress when life gets in the way, keeping momentum intact.

## 🎨 Design Philosophy

HabitArc follows a **"Floating & Curved"** aesthetic — a full OS-grade visual language:

| Principle | Description |
|---|---|
| 🪐 **Floating Pill Header** | Detached navigation bar floating at the top — clean, "OS" workspace feel |
| · **Dot-Grid Canvas** | Subtle professional dot-grid background adding depth and reinforcing the Operating System aesthetic |
| ⬭ **Global Curvature** | 32px border-radius standard across all panels and pill-shaped interactive elements |
| 🪟 **Deep Glassmorphism** | `backdrop-filter: blur(20px)` with 1px border highlights and saturation-optimized blends |
| 🎊 **Juicy Feedback** | Staggered entrances, springy habit pops, and dopamine-hit confetti bursts via Framer Motion |

## 🚀 Getting Started

### Prerequisites
- **Node.js** v16 or higher
- **npm** or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Arnaviitp/Kalyug-Health-Tracker.git

# 2. Navigate to the project directory
cd Kalyug-Health-Tracker

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to enter the Arc.
